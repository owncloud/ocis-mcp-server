# MCP 2026-07-28 Transport Implementation Plan (Phase 1)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the HTTP and stdio transports speak MCP 2026-07-28 while keeping 2025-11-25 clients working, with no auth change.

**Architecture:** Move server construction and the HTTP handler out of `main.go` into a new `internal/mcpserver` package so they can be tested in process. Set the SDK stateless options, cache hints and hardening there. Tests drive it with the SDK client over in-memory and HTTP transports, plus raw HTTP for header and error-code checks.

**Tech Stack:** Go 1.26, `github.com/modelcontextprotocol/go-sdk` v1.8.0 (`mcp`, `jsonrpc`), `net/http/httptest`.

**Spec:** `docs/superpowers/specs/2026-11-27-mcp-2026-07-28-and-oidc-design.md` (decisions in `DECISIONS.md`, evidence in `ARCHAEOLOGY.md`).

## Global Constraints

- go-sdk stays at v1.8.0. No new dependency in this phase.
- `StreamableHTTPOptions.Stateless` is `true`. Caches: discover and the four list methods `ttlMs=300000` `cacheScope="public"`; `resources/read` `ttlMs=30000` `cacheScope="private"`.
- A missing resource returns the SDK's resource-not-found error, JSON-RPC `-32602`.
- stdio behavior and credentials are unchanged. No auth change on HTTP in this phase.
- Roots, Sampling and Logging are untouched.
- Table-driven tests, no skipped tests, no TODO comments in committed code.
- Commits: `git commit -s -S`, conventional type, trailers `🤖 Generated with Claude Code` then `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`. Never force push.
- Docs and commit messages are terse with no em dashes.
- Never print, log or commit tokens or secrets. Test fixtures use obvious dummy values.
- Gates before the checkpoint: `make test`, `make lint`, `make reuse` and `make docker-build` all green.

## Review Focus

Likely to bite, not covered by a happy-path test of the spec. Each line has a test in the named task.

1. Header and body disagree on a 2026-07-28 request (`Mcp-Method` says one thing, body another). Expect 400 with `-32020` and the tool never runs. Task 2.
2. Client disconnects mid tool call. Expect the in-flight oCIS request to be cancelled, since closing the stream is cancellation. Task 2.
3. A legacy client sends GET, DELETE or a stale `Mcp-Session-Id`. Expect 405 or ignore, never 500. Task 2.
4. Oversized body, cross-origin browser POST and a rebinding `Host` header. Expect 413, 403 and 403. Task 4.
5. Unknown resource URI and unknown tool name. Expect JSON-RPC errors, not panics or 500. Task 3.

## File Structure

- Create `internal/mcpserver/server.go`: `New`, the cache-hint function and the option wiring.
- Create `internal/mcpserver/http.go`: `NewHTTPHandler` and `NewHTTPServer`.
- Create `internal/mcpserver/helpers_test.go`: fake oCIS, server and client constructors, raw POST helper.
- Create `internal/mcpserver/server_test.go`: in-memory (stdio-path) tests and registration counts.
- Create `internal/mcpserver/http_test.go`: HTTP behavior tests.
- Modify `cmd/ocis-mcp-server/main.go`: use the new package.
- Modify `Makefile`, `.github/workflows/ci.yml`: REUSE gate.

Protocol strings used in tests: latest `2026-07-28`, legacy `2025-11-25`. Raw 2026-07-28 POST body shape:

```json
{"jsonrpc":"2.0","id":1,"method":"tools/list","params":{"_meta":{"io.modelcontextprotocol/protocolVersion":"2026-07-28","io.modelcontextprotocol/clientCapabilities":{}}}}
```

with headers `Content-Type: application/json`, `Accept: application/json, text/event-stream`, `MCP-Protocol-Version: 2026-07-28`, `Mcp-Method: tools/list`.

### Task 2: Stateless HTTP serving 2026-07-28

- [ ] **Step 1: Write the failing tests** in `http_test.go`, table-driven where inputs vary:

  - `TestHTTPLegacyClient`: SDK client pinned to `2025-11-25` over `mcp.StreamableClientTransport{Endpoint: url, DisableStandaloneSSE: true}` lists tools and calls `ocis_get_version`.
  - `TestHTTPLatestClient`: SDK client at default version does the same.
  - `TestHTTPMethodMethods` (table: GET, DELETE): status 405 and `Allow` header `POST`.
  - `TestHTTPStaleSessionID`: legacy raw POST with a bogus `Mcp-Session-Id` header gets a non-5xx status.
  - `TestHTTPHeaderValidation` (table: `Mcp-Method` mismatching body gives 400 and error code `-32020`; `MCP-Protocol-Version` header disagreeing with `_meta` gives 400; unsupported version `2099-01-01` gives 400 and `-32022`). In the mismatch case, assert the fake oCIS saw zero requests.
